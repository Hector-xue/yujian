# 路线图

## 0.1（已发布）
单设备本地账本、对话记账、收件箱、查询、记忆、人格、模型配置、导入导出。

## 0.2 智能化（已发布）
- Android 通知监听 + 通知模板库（微信/支付宝/银行/购物出行平台），三种自动化模式（确认 / 智能 / 静默，静默必有日志与一键撤销）
- Android 支付页识别（无障碍，可选）：补通知监听抓不到的前台付款；只看名单 App、只在「支付成功」页读一次
- 截图 / 小票识别（视觉模型或本地 OCR）
- 语音输入
- 周期账单、预算与预警、异常支出
- Flutter Desktop；MCP Server（桌面内置：只读工具 + propose 工具，不给直写）

## 0.3 生态与同步（已发布，iOS 除外）
- 可选 Yujian Server：同步中继（变更日志 + 墓碑）、加密备份、AI 代理、OCR、MCP
- Docker Compose、自托管文档
- Persona SDK、导入适配器 SDK、通知模板贡献流程、Webhook
- iOS（快捷指令 / 分享 / 导入）

## 0.4 补齐（已发布）
- 交易编辑、分类/账户管理、forecast 与存钱算术、异常支出、系统分享进余见
- App 内语音输入、Anthropic 原生 Provider、仅本地模型 / 脱敏开关
- 手工列映射、Markdown 月报、SQLite 文件备份与恢复、服务端 AI 代理
- 人格头像与主题色

## 0.9 财富游戏层（已发布）
- 目标（心愿 / 应急金 / 还清 / 里程碑）：虚拟或真实锁仓，存入是真实转账，兑现是从锁仓花出去；定额 / 工资比例 / 零头周结 / 任务奖励四种存入规则；优先级 = 发薪日分钱顺序
- 四个真指标：可花的（流动资产 − 锁仓 − 发薪前固定支出）、今天还能花、生存月数（= 等级）、储蓄率 / 净资产 / 收入分线；全部账本推导、页面写明依据
- 周任务：五种本机判定器 + 模板 + 模型候选（只进候选）；周日结算；完成奖励是往目标里存真钱
- 成就：账本事实触发，一次性，带依据；没有商店 / 签到 / 虚拟币
- 三个仪式：发薪日分钱卡（一组转账草稿进收件箱）、周一任务卡、月末复盘（对话里由人格讲）；都在打开 App 时触发，不发系统通知
- 收件箱代价行：「这笔 = 日本游晚 4 天」；表达层总开关可关，目标页不受影响
