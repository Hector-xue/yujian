# 路线图

## 0.1（已发布）
单设备本地账本、对话记账、收件箱、查询、记忆、人格、模型配置、导入导出。

## 0.2 智能化
- Android 通知监听 + 通知模板库（微信/支付宝/银行），三种自动化模式（确认 / 智能 / 静默，静默必有日志与一键撤销）
- 截图 / 小票识别（视觉模型或本地 OCR）
- 语音输入
- 周期账单、预算与预警、异常支出
- Flutter Desktop；MCP Server（桌面内置：只读工具 + propose 工具，不给直写）

## 0.3 生态与同步
- 可选 Yujian Server：同步中继（变更日志 + 墓碑）、加密备份、AI 代理、OCR、MCP
- Docker Compose、自托管文档
- Persona SDK、导入适配器 SDK、通知模板贡献流程、Webhook
- iOS（快捷指令 / 分享 / 导入）

## 不做
银行直连、投资建议、企业财务、让模型直接改账。
