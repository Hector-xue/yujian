# 通知模板

Android 自动记账有两条路，都汇到同一套模板：

1. **通知监听**：读支付类通知。内置覆盖微信、支付宝、常见银行、购物 / 外卖 / 出行平台（淘宝、天猫、京东、拼多多、美团、饿了么、抖音、滴滴、12306、携程……）和一个泛用兜底；物流 / 骑手 / 营销类直接忽略；认不出的通知会进收件箱附原文，不会丢。
2. **支付页识别**（无障碍服务，可选）：微信 / 支付宝付款时 App 在前台，系统不弹通知，通知监听抓不到。这条路在名单里的 App 出现「支付成功」页面时读一次金额和商户，拼成 `支付成功 ¥13.80 商户：xxx` 交给同一套模板（title 带 App 名，包名是真实包名）。名单和解析在 `PaymentScreenService.kt` / `PaymentScreenParser.kt`。

模板从通知正文里抽金额/方向/商户。

自己加一条（App「更多 → 自动记账 → 自定义模板」）：

| 字段 | 说明 |
|---|---|
| id | 名字 |
| packages | 包名列表，空 = 任意 |
| text_re | 正文正则，必须有 `(?<amount>数字)` 分组，可选 `(?<merchant>…)` |
| direction | expense / income / transfer；不填按关键词判 |
| account_hint | 账户名线索（"招行"），按别名匹配到你的账户 |

例：校园卡 `消费(?<amount>\d+\.\d\d)元` → expense，账户线索"饭卡"。

用户模板优先于内置。欢迎把通用的模板提到 Issue（模板：解析不对）。
