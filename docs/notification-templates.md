# 通知模板

Android 通知自动记账靠模板从通知正文里抽金额/方向/商户。内置覆盖微信、支付宝、常见银行和一个泛用兜底；认不出的通知会进收件箱附原文，不会丢。

自己加一条（App「更多 → 自动记账 → 自定义模板」）：

| 字段 | 说明 |
|---|---|
| id | 名字 |
| packages | 包名列表，空 = 任意 |
| text_re | 正文正则，必须有 `(?<amount>数字)` 分组，可选 `(?<merchant>…)` |
| direction | expense / income / transfer；不填按关键词判 |
| account_hint | 账户名线索（"招行"），按别名匹配到你的账户 |

例：校园卡 `消费(?<amount>\d+\.\d\d)元` → expense，账户线索"饭卡"。

用户模板优先于内置。欢迎把通用的模板提到 Issue（模板：解析不对）。
