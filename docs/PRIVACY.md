# 隐私说明（模板，自托管者可按需修改）

余见默认把所有财务数据存在你的设备上（Android：应用私有目录；Web：浏览器 IndexedDB）。

- 不上传账本。没有官方服务器，也没有统计上报。
- 只有当你在"模型与人格"里配置了模型端点，解析文本时才会把**你输入的那句话**、账户名和分类名发送到你指定的端点；账本记录不会发送。不配置模型时一切在本机完成。
- 陪聊：配置了模型后，对话里的闲聊会把**这句话、最近几轮对话、你让它记住的事，以及几行汇总数字（今天 / 本月支出收入、预算、最近几笔、目标名与进度）**发到你指定的端点；不发送整本账。"它记住的事"只存本机，可在"模型与人格"里逐条删除。
- 财富游戏：目标 / 可花的 / 等级 / 周任务 / 成就全部在本机算。配置了模型时，每周第一次打开会把账本速览和目标名发给端点提几个任务候选（只进候选，用户勾选才生效），每月第一次打开会把规则生成的复盘文字发给端点用人格口吻重讲一遍（数字不变）。纯本地模式下这两条都不发生。
- 自动记账（Android，均需你在系统里显式授权，随时可关）：
  - 通知监听：只读支付类通知，不读短信。
  - 支付页识别（无障碍服务）：只对微信、支付宝、云闪付及常见购物 / 外卖 / 出行 App 生效，只在页面出现"支付成功"字样的那一刻读一次金额和商户；读到的文字只在本机进入收件箱或账本，不发送到任何地方。代码见 `apps/yujian/android/.../PaymentScreenService.kt`。
- 「支持余见」（更多 → 支持余见，¥1，自觉制）：页面不联网、不上报是否支持过；"支持过"只是账本画像里的一个日期（随同步走）。付款在支付宝 / 微信里完成，余见拿不到任何支付信息；开着支付页识别 / 通知记账时"付完自动关提醒"也只是本机看到一笔 ¥1 的支出。
- API Key 存在系统安全存储（Android Keystore / 浏览器 Web Crypto），不出现在日志与导出文件里。
- 导出与备份文件由你自己保管；备份包含全部交易与记忆映射。
- 删除应用即删除本机数据；请先备份。
