# 隐私说明（模板，自托管者可按需修改）

余见默认把所有财务数据存在你的设备上（Android：应用私有目录；Web：浏览器 IndexedDB）。

- 不上传账本。没有官方服务器，也没有统计上报。
- 只有当你在"模型与人格"里配置了模型端点，解析文本时才会把**你输入的那句话**、账户名和分类名发送到你指定的端点；账本记录不会发送。不配置模型时一切在本机完成。
- API Key 存在系统安全存储（Android Keystore / 浏览器 Web Crypto），不出现在日志与导出文件里。
- 导出与备份文件由你自己保管；备份包含全部交易与记忆映射。
- 删除应用即删除本机数据；请先备份。
